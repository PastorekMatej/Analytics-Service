- résumé:
  L’étudiante a nettement gagné en maîtrise discursive (argumentation, connecteurs, conditionnel) et en fluidité. Les erreurs lourdes de passé composé (accords avec avoir, auxiliaires) et l’ordre des mots se raréfient. Les déterminants, les accords de base et les prépositions restent cependant des zones de fragilité, avec des interférences du slovaque encore visibles.

TENDANCES D’ÉVOLUTION:
- G01 (accord du participe passé avec avoir): ≈6 occurrences concentrées à la leçon 4 → 0 dans les leçons 13–15.
- G08 (ordre des mots): 3 occurrences dans les leçons 2–5 → 0 dans les leçons 13–15.
- G09 (confusion des temps composés): 2 occurrences (leçons 4–5) → 0 dans les leçons 13–15.
- G10 (subjonctif/conditionnel): 1 erreur tôt (“Bien que ma vie a changé”, leçon_2) → emploi correct ensuite (“pour qu’il ait…”, leçon_9_2).
- G07 (articles/déterminants): ≈10 occurrences dans les leçons 1–7 → 6–7 occurrences encore dans les leçons 13–15 (persistance élevée).
- G06 (prépositions/compléments à l’infinitif/relatifs): ≈5 occurrences dans les leçons 1–7 → 2 occurrences dans les leçons 13–15 (réduction partielle).
- G05 (accords/conjugaisons de base): ≈8 occurrences dans les leçons 2–7 → ≈6 occurrences encore dans les leçons 13–15 (persistance).
- V01 (faux amis / formes inexactes): ≈4 occurrences tôt → 3 occurrences dans les leçons 13–15 (stabilité).
- V04 (collocations non naturelles): ≈3 occurrences tôt → 2 occurrences dans les leçons 13–15 (légère amélioration).
- V05 (interférence slovaque): 3 occurrences tôt → 2 occurrences dans les leçons 13–15 (stabilité).
- S05 (formulations lourdes/maladroites): récurrent mais un peu mieux organisé dans les textes récents (phrases plus structurées, connecteurs variés).

Conclusion synthétique:
- Les progrès sont nets: meilleure organisation du discours, variété des connecteurs, apparition maîtrisée du conditionnel et du subjonctif, disparition quasi totale des erreurs d’auxiliaire/accord au passé composé et de l’ordre des mots.
- Les priorités actuelles: sécuriser les déterminants (G07), les accords de base (G05) et les prépositions/constructions (G06), réduire les calques lexicaux et améliorer les collocations (V01/V04/V05).
- Niveau global: passage de A2+ (départ) à B1+ (actuel), avec une marge vers B2 dès que la précision grammaticale et l’idiomaticité seront stabilisées.
