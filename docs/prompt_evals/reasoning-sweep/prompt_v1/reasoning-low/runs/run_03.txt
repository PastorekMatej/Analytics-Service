ÉVOLUTION_GLOBALE:
- évolution de niveau: "A2 → B1"
- résumé: L’étudiante a nettement gagné en ampleur textuelle (lettres argumentées, consignes, récits au passé) et en contrôle des structures complexes (subordonnées, hypothèses, registre semi‑formel). Les erreurs de passé composé (auxiliaire/accord) ont quasi disparu, l’ordre des mots s’améliore. Persistents: prépositions/constructions à l’infinitif, articles/déterminants, accords de base, quelques négations mal formées et emplois fautifs du subjonctif/conditionnel. Autocorrections visibles dès les leçons 15–15_2, signe de conscience métalinguistique accrue.

TENDANCES D’ÉVOLUTION:
- G01 (participe passé/auxiliaire au passé composé): ≈8–10 occurrences concentrées leçons 2–4 → 0 dans 13–15_2.
- G08 (ordre des mots, placement adverbes/pronoms): ≈6 occurrences leçons 4–5 → 1 isolée leçon 12 → 0 dans 15–15_2.
- G05 (accords/conjugaisons de base): ≈10 occurrences leçons 2–7 → 3–4 leçon 13 → 1–2 dans 15–15_2.
- V04 (collocations plus naturelles): amélioration sensible dans 15–15_2 (auto‑révisions), même si 2–3 calques persistent.
- Style: progression de la structuration argumentative (connecteurs, exemples, reformulations), diversité des genres textuels (courrier pro, argumentaire, récit), et apparition d’auto‑corrections explicites dès la leçon 15.

ERREURS_RÉCURRENTES:
GRAMMAIRE:
- type: G07
  pattern: Mauvais emploi des articles/déterminants (absence, genre, contraction, partitif)
  occurrences: ≈14
  exemples:
    - "la langue français" → "la langue française" (leçon_1)
    - "association des vos élèves" → "de vos élèves" (leçon_5_2)
    - "des belles photos" → "de belles photos" (leçon_5)
    - "la départ de Baptiste" → "le départ" (leçon_9_2)
    - "A école" → "À l’école" ; "du anglais" → "de l’anglais" ; "le langue" → "la langue" (leçon_15)
    - "cet expérience" → "cette expérience" (leçon_15_2)

- type: G06
  pattern: Utilisation incorrecte des prépositions / constructions à l’infinitif
  occurrences: ≈15
  exemples:
    - "j’ai commencé apprendre" → "j’ai commencé à apprendre" (leçon_1)
    - "As‑tu quelque chose nouvelle ?" → "… quelque chose de nouveau ?" (leçon_2)
    - "en nuit" → "la nuit / dans la nuit" (leçon_4)
    - "dans l’école" → "à l’école" (leçon_5_2)
    - "recommencent être ouvertes" → "recommencer à être ouvertes / rouvrent" (leçon_6_2)
    - "t’aider avec chercher" → "t’aider à chercher" ; "attends pour recevoir" → "attends de recevoir" (leçon_7_1)
    - "quelque chose différent" → "quelque chose de différent" ; "savoir travailler à leurs outils" → "… utiliser leurs outils" ; "un cours d’apprendre utiliser" → "un cours pour apprendre à utiliser" (leçon_10)
    - "en langue que je voulais apprendre" → "dans la langue…" (leçon_15)
    - "parler en français" → "parler français" ; "rencontrer avec la vie" → "faire l’expérience de / découvrir la vie…" (leçon_15_2)

- type: G05
  pattern: Accords de base (genre/nombre) et conjugaisons
  occurrences: ≈12
  exemples:
    - "le première fois" → "la première fois" ; "ce gens" → "ces gens" (leçon_2)
    - "j’étais… stressé / heureux" → "stressée / heureuse" (leçon_5)
    - "très réussi / satisfée" → "très réussie / satisfaite" (leçon_6_1)
    - "varieux" → "variés" (leçon_6_2)
    - "tu envoie" → "tu envoies" (leçon_7_1)
    - "les professeurs étaient très encourageant et rassurant" → "encourageants et rassurants" (leçon_13)

- type: G08
  pattern: Ordre des mots (adverbes, subordonnants, pronoms)
  occurrences: ≈8
  exemples:
    - "Tu me vraiment manques" → "Tu me manques vraiment" (leçon_4)
    - "c’est pour ça j’étais triste" → "c’est pour ça que j’étais triste" (leçon_5)
    - "Et je dois dire j’aime…" → "… dire que j’aime…" (leçon_2)
    - "vous vous pouvez garer" → "vous pouvez vous garer" (leçon_5_2)
    - "c’est que vous voyez mener…" → "c’est celle que vous voyez… / qui mène…" (leçon_5_2)
    - "… et dans je suis…" → "… et qui me…" (leçon_12)

- type: G01
  pattern: Passé composé: auxiliaire/accord du participe passé
  occurrences: ≈9
  exemples:

    - "j’ai passée la nuit" → "j’ai passé la nuit" (leçon_4)
    - "j’ai vue / visitée…" → "j’ai vu / visité…" (leçon_4)
    - "j’y restée trois jours" → "j’y suis restée…" (leçon_4)
    - "j’ai voyagée" → "j’ai voyagé" (leçon_4)

- type: G03
  pattern: Erreur de négation (ordre/placement)
  occurrences: 2

- type: G10
  pattern: Usage fautif du subjonctif/conditionnel
