GRAMMAIRE
- type: G01
  pattern: Accord/formation du passé composé avec avoir (participe mal accordé ou mal formé)
  occurrences: ≈12
  exemples:
    - "j’ai passée la nuit" → "j’ai passé la nuit" (2024-03-19)
    - "j’ai vue le Musée national" → "j’ai vu le musée national" (2024-03-19)
    - "qui a donner des roses" → "qui a donné des roses" (2024-05-08)

- type: G03
  pattern: Négation fautive (placement de ne/pas/pronoms)
  occurrences: ≥2
  exemples:
    - "qui je n’ai connu pas" → "que je ne connaissais pas" (2024-02-05)
    - "vous n’avez me pas croire" → "vous ne me croirez pas" (2024-12-20)

- type: G05
  pattern: Accords de base (genre/nombre/personne; adjectifs/verbes)
  occurrences: 20+
  exemples:

    - "les enfants voudrions" → "les enfants voudraient" (2024-11-20)
    - "professeurs … encourageant" → "encourageants" (2024-12-20)

- type: G06

- type: G07

- type: G08

Conclusion synthétique:
- L’étudiante passe d’un A2 communicatif à un B1 fonctionnel: elle gère des tâches variées (courriels/lettres formelles, avis argumentés), utilise mieux les temps du passé et introduit le conditionnel. Les erreurs de surface (G05/G06/G07/G08) et de style (S02/S05) restent fréquentes mais moins bloquantes. Priorités: verrouiller les schémas "verbe + à/de + infinitif", sécuriser articles/contractions, automatiser les accords de base, alléger la syntaxe (subordination, ponctuation) et fiabiliser les collocations pour consolider un B1 solide.
